CSS Gradients: Linear, Radial & Conic Color Stops & Oklch Color Spaces

CSS gradients generate smooth mathematical transitions between colors without bitmap image bandwidth. Modern CSS supports linear gradients along angle vectors, radial circular transitions, and conic 360-degree angle sweeps in wide-gamut color spaces.

Functions linear-gradient(), radial-gradient(), conic-gradient(), repeating-linear-gradient()
Interpolation Modes in oklch, in srgb, in oklab (CSS Color Module Level 4)
Angle Syntax deg, rad, turn, to top/right/bottom/left
Standard W3C CSS Images Module Level 3 & Level 4

Implementation & Code Examples

Modern Wide-Gamut Linear Gradient

.hero-banner {
  /* Linear gradient using modern OKLCH color interpolation to prevent gray dead zones */
  background: linear-gradient(135deg in oklch, #6366f1, #ec4899);
}

Conic Color Wheel Sweep

.pie-chart {
  background: conic-gradient(#3b82f6 0% 35%, #10b981 35% 70%, #f59e0b 70% 100%);
  border-radius: 50%;
}

Browser Rendering Performance & Hardware Compositing

Executing CSS Gradients in modern web applications requires optimizing layout rendering across the browser rendering pipeline:

  • GPU Compositor Promotion: Restrict high-frequency dynamic transitions to compositor-only CSS properties (transform and opacity) to avoid triggering costly CPU layout reflows and repaints.
  • Layout Thrashing Prevention: Decouple DOM geometry measurements from subsequent style write operations to eliminate forced synchronous reflow cycles and preserve 60 FPS scrolling.
  • Subpixel Antialiasing: Design visual components with hardware-accelerated vector units and clamp scaling boundaries to eliminate visual pixel rounding jitter on high-DPI displays.

Frequently Asked Questions & Troubleshooting

What is the 'gray dead zone' in CSS gradients and how does OKLCH fix it?

Standard sRGB interpolation creates a muddy, desaturated gray band in the midpoint between complementary colors (e.g. blue and yellow). Specifying in oklch interpolates through uniform perceptual lightness, keeping colors vibrant.

Can CSS gradients be animated with CSS transitions?

Historically, browser engines cannot interpolate between background-image gradient functions. Modern CSS solves this using @property to declare typed custom properties (like <color> or <percentage>) that animate smoothly.
