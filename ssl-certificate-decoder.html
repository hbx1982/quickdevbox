Public Key Infrastructure (PKI) and X.509 Certificate Standards

X.509 is the universal ITU-T standard defining public key certificates for TLS/SSL internet security. Digital certificates bind a public key to an authenticated organization or domain identity signed by a trusted Certificate Authority (CA).

1. ASN.1 Structures and PEM Base64 Encoding

X.509 certificate data structures are defined in Abstract Syntax Notation One (ASN.1) and serialized into binary DER format. PEM (Privacy-Enhanced Mail) encoding wraps binary DER data in Base64 lines bordered by -----BEGIN CERTIFICATE----- and -----END CERTIFICATE----- headers.

2. Subject Alternative Name (SAN) Multi-Domain Extensions

Modern web browsers ignore legacy CommonName (CN) fields in favor of Subject Alternative Name (SAN) extension fields, allowing a single SSL certificate to secure multiple fully qualified domain names (FQDNs) and wildcard domains.
