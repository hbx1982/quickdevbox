Web Font Engineering: WOFF2 Brotli Compression & CSS font-display Policies

Web Open Font Format 2 (WOFF2) uses the Brotli entropy compression algorithm to reduce web font payload sizes by ~30% compared to legacy WOFF1. Combining WOFF2 with @font-face and font-display: swap prevents Flash of Invisible Text (FOIT).

Compression Algorithm Brotli Compression (RFC 7932) applied to OpenType / TrueType glyph tables
W3C Recommendation WOFF File Format 2.0 (W3C Recommendation 01 March 2018)
FOIT Defense font-display: swap (Immediately renders fallback font while downloading)
Browser Support Supported across 97%+ of global web browsers

Implementation & Code Examples

Production @font-face CSS Declaration

@font-face {
  font-family: 'Inter';
  font-style: normal;
  font-weight: 400 700;
  /* font-display: swap eliminates Flash of Invisible Text (FOIT) */
  font-display: swap;
  src: url('/fonts/inter-variable.woff2') format('woff2 supports variations'),
       url('/fonts/inter-variable.woff2') format('woff2');
  unicode-range: U+0000-00FF, U+0131, U+0152-0153;
}

Browser Rendering Performance & Hardware Compositing

Executing Web Font Engineering in modern web applications requires optimizing layout rendering across the browser rendering pipeline:

  • GPU Compositor Promotion: Restrict high-frequency dynamic transitions to compositor-only CSS properties (transform and opacity) to avoid triggering costly CPU layout reflows and repaints.
  • Layout Thrashing Prevention: Decouple DOM geometry measurements from subsequent style write operations to eliminate forced synchronous reflow cycles and preserve 60 FPS scrolling.
  • Subpixel Antialiasing: Design visual components with hardware-accelerated vector units and clamp scaling boundaries to eliminate visual pixel rounding jitter on high-DPI displays.

Frequently Asked Questions & Troubleshooting

What is the difference between FOIT and FOUT in web font loading?

FOIT (Flash of Invisible Text) hides text completely for up to 3 seconds while fonts download, displaying a blank screen. FOUT (Flash of Unstyled Text) renders a system fallback font immediately and swaps once WOFF2 arrives.

Why is WOFF2 superior to TrueType (TTF) and OpenType (OTF) on the web?

TTF and OTF contain uncompressed font tables designed for local operating system installation. WOFF2 compresses glyph tables with Brotli and includes web metadata, cutting bandwidth usage in half.
