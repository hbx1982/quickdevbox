Understanding OSI Layer 2 MAC Address Structures

A Media Access Control (MAC) address is a unique 48-bit (EUI-48) or 64-bit (EUI-64) hardware address assigned to Network Interface Controllers (NIC) operating at Data Link Layer 2. MAC addresses facilitate frame delivery across physical Ethernet and Wi-Fi local area networks.

1. OUI Allocation and Bit Flag Inspection

The first 24 bits (3 octets) form the Organizationally Unique Identifier (OUI) managed by the IEEE Registration Authority to identify hardware manufacturers (such as Cisco, Apple, or Intel). Inspecting the first octet reveals vital network flags:

  • Least Significant Bit (Bit 0): 0 indicates a Unicast address destined for a single NIC; 1 indicates a Multicast or Broadcast frame.
  • Second Least Significant Bit (Bit 1): 0 indicates a Globally Unique OUI assigned by IEEE; 1 indicates a Locally Administered address (randomized for privacy).

2. Conversion between Colon, Hyphen, and Cisco Formats

// Normalizing MAC Strings to Standard IEEE Format
function normalizeMacAddress(macStr) {
  let hex = macStr.replace(/[^a-fA-F0-9]/g, '');
  if (hex.length !== 12) throw new Error("Invalid MAC string length");
  return hex.match(/.{1,2}/g).join(':').toUpperCase();
}
