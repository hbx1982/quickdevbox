MAC Address OUI: IEEE EUI-48 Architecture & Hardware Vendor Identification

Media Access Control (MAC) addresses are 48-bit unique identifiers assigned to Network Interface Controllers (NICs). The first 24 bits represent the Organizationally Unique Identifier (OUI) assigned by IEEE to identify the hardware manufacturer.

Python 3 OUI Lookup Function

def parse_mac_oui(mac_address: str):
    clean_mac = mac_address.replace(":", "").replace("-", "").upper()
    oui = clean_mac[:6]
    first_byte = int(clean_mac[:2], 16)
    is_multicast = bool(first_byte & 0x01)
    is_locally_administered = bool(first_byte & 0x02)
    return {"oui": oui, "multicast": is_multicast, "local_admin": is_locally_administered}
