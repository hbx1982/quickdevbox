URL Query String to JSON: URLSearchParams, Array Brackets & Type Coercion

Parsing URL query parameters into JSON decodes key-value query strings (e.g. ?filter=active&sort=desc) into structured JSON. It handles percent-decoding, repeated parameter aggregation, and array bracket notations (key[]=val).

Query Syntax Standard IETF RFC 3986 / WHATWG URL Living Standard
Array Notation Parsing Supports repeated keys (a=1&a=2) and bracket keys (items[]=x&items[]=y)
Decoding Standard decodeURIComponent applied to all percent-encoded octets
Type Coercion Optional coercion of numeric and boolean string values

Implementation & Code Examples

JavaScript Query String Parser

function queryParamsToJson(queryString) {
  const cleanQuery = queryString.replace(/^\?/, '');
  const params = new URLSearchParams(cleanQuery);
  const result = {};

  for (const [key, value] of params.entries()) {
    const cleanKey = key.replace(/\[\]$/, '');
    if (key.endsWith('[]') || result.hasOwnProperty(cleanKey)) {
      if (!Array.isArray(result[cleanKey])) {
        result[cleanKey] = result.hasOwnProperty(cleanKey) ? [result[cleanKey]] : [];
      }
      result[cleanKey].push(value);
    } else {
      result[cleanKey] = value;
    }
  }
  return result;
}
console.log(queryParamsToJson('?category=dev&tags[]=js&tags[]=ts&page=1'));

Architectural Design & High-Throughput Pipeline Optimization

Integrating URL Query String to JSON into continuous delivery pipelines requires balancing lexical analysis latency with memory consumption:

  • Stream-Based Tokenization: For large data buffers exceeding 1MB, avoid synchronous in-memory string parsing on the main event thread. Stream input tokens through chunked pipelines to prevent event-loop thread starvation.
  • Defensive Parsing & Exception Isolation: Always wrap syntax transformations inside structured exception handlers to isolate malformed inputs, truncated payloads, and illegal control characters from crashing downstream microservices.
  • Character Encoding Verification: Enforce strict UTF-8 input normalization at API gateways to prevent byte-order mark (BOM) anomalies, truncated multi-byte sequences, and surrogate pair deserialization errors.

Frequently Asked Questions & Troubleshooting

Why does standard URLSearchParams.get() discard repeated query parameters?

URLSearchParams.get(name) only returns the very first matching value. To retrieve all values for repeated keys (e.g. ?tag=a&tag=b), call URLSearchParams.getAll(name).

How does query parameter pollution lead to security vulnerabilities?

If frontends and backend servers parse repeated parameters differently (e.g. one takes the first value, the other takes the last), attackers can bypass WAF validation rules (HTTP Parameter Pollution).
