Color Vision Deficiency (CVD): Brettel & Machado LMS Color Matrices

Simulating Color Vision Deficiency (CVD) transforms sRGB colors into LMS cone space (Long, Medium, Short wavelengths) to simulate Protanopia, Deuteranopia, Tritanopia, and Achromatopsia, ensuring accessible UI state signifiers.

Deficiency Types Protanopia (Red-blind), Deuteranopia (Green-blind), Tritanopia (Blue-blind), Achromatopsia (Monochrome)
Mathematical Model Brettel (1997) & Machado (2009) LMS Cone Response Transformation Matrices
Prevalence Baseline ~8% of males and ~0.5% of females have some form of inherited CVD
Accessibility Rule WCAG 2.1 § 1.4.1: Color must not be used as the sole visual means of conveying information

Memory Management & Client-Side Buffer Handling

Processing Color Vision Deficiency (CVD) directly in browser client memory demands proactive memory cleanup and resource limits:

  • Blob Lifecycle Cleanup: Always invoke URL.revokeObjectURL() once binary image blobs finish loading to release allocated texture memory and prevent browser tab memory exhaustion.
  • Offscreen Canvas Workers: Offload CPU-heavy pixel matrix loops and color quantization algorithms to background Web Workers using OffscreenCanvas to keep user interactions smooth.
  • Texture Dimension Clamping: Verify source image dimensions prior to canvas allocation to prevent mobile browser crashes caused by device-specific maximum canvas texture limits.

Frequently Asked Questions & Troubleshooting

Why is using green for 'success' and red for 'error' dangerous for CVD users?

Protanopia and Deuteranopia (red-green color blindness) affect the vast majority of color-blind individuals, making red and green appear as identical shades of yellowish-brown. Always accompany color cues with icons (checkmark / warning triangle) or text labels.

What is the difference between an 'anomaly' (e.g. Deuteranomaly) and an 'opia' (e.g. Deuteranopia)?

Anomalous trichromacy means one cone pigment is shifted in wavelength sensitivity (partial deficiency). Dichromacy (ending in 'opia') means the cone type is completely missing from the retina.
