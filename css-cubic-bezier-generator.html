CSS Cubic Bezier Curves: Acceleration Curves, Splines & Spring Transitions

Cubic Bezier curves define smooth easing transitions in CSS using four control points: P0(0,0), P1(x1,y1), P2(x2,y2), and P3(1,1). Setting y-coordinates above 1.0 or below 0.0 simulates physical spring and bounce easing.

Mathematical Formula B(t) = (1-t)^3*P0 + 3(1-t)^2*t*P1 + 3(1-t)*t^2*P2 + t^3*P3, where 0 <= t <= 1
Coordinate Boundaries x1 and x2 MUST be within [0, 1]; y1 and y2 can exceed [0, 1] for bounce
Standard Keyword Curves ease (0.25, 0.1, 0.25, 1), ease-in (0.42, 0, 1, 1), ease-out (0, 0, 0.58, 1)
Standard W3C CSS Easing Functions Level 1

Implementation & Code Examples

Elastic Spring Bounce Easing

.modal-popup {
  /* y2 = 1.4 creates an overshoot bounce effect before settling at 1.0 */
  transition: transform 0.5s cubic-bezier(0.34, 1.56, 0.64, 1);
  transform: scale(1);
}
.modal-hidden {
  transform: scale(0.7);
}

Smooth Material Design Deceleration

.drawer-slide {

Browser Rendering Performance & Hardware Compositing

Executing CSS Cubic Bezier Curves in modern web applications requires optimizing layout rendering across the browser rendering pipeline:

  • GPU Compositor Promotion: Restrict high-frequency dynamic transitions to compositor-only CSS properties (transform and opacity) to avoid triggering costly CPU layout reflows and repaints.
  • Layout Thrashing Prevention: Decouple DOM geometry measurements from subsequent style write operations to eliminate forced synchronous reflow cycles and preserve 60 FPS scrolling.
  • Subpixel Antialiasing: Design visual components with hardware-accelerated vector units and clamp scaling boundaries to eliminate visual pixel rounding jitter on high-DPI displays.

Frequently Asked Questions & Troubleshooting

Why does the CSS parser reject cubic-bezier values with x-coordinates outside [0, 1]?

In animation timing functions, the X-axis represents progression in time. Time cannot flow backwards; therefore, x1 and x2 must remain strictly between 0 and 1 to prevent non-functional time loops.

How do you achieve realistic elastic overshoot using cubic-bezier?

Set y2 above 1.0 (e.g. cubic-bezier(0.175, 0.885, 0.32, 1.275)). The animation will accelerate past its target value and snap back, simulating spring physics.
