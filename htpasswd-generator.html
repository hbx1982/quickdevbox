Apache .htpasswd: HTTP Basic Authentication & Hashing Formats

Apache HTTP Server and Nginx use .htpasswd flat files to enforce HTTP Basic Authentication. Supported password formats include modern Bcrypt ($2y$), Apache APR1 MD5 ($apr1$), and legacy crypt.

Infrastructure Configuration & Command Examples

Apache htpasswd CLI

# Create a new .htpasswd file with Bcrypt encryption (cost 12)
htpasswd -B -C 12 -c /etc/nginx/.htpasswd admin

# Add an additional user without overwriting the file
htpasswd -B -C 12 /etc/nginx/.htpasswd developer

Nginx Basic Auth Configuration

location /admin {
    auth_basic "Restricted Administrator Portal";
    auth_basic_user_file /etc/nginx/.htpasswd;
}
