CSS Animations & Keyframes: GPU Compositing, Timing Curves & Fill Modes

CSS Animations interpolate property values across time using @keyframes rules. High-performance 60 FPS animations restrict mutations to transform and opacity, executing entirely on the browser's asynchronous compositor thread.

Hardware Acceleration Compositor-only properties (transform, opacity) avoid layout/paint steps
Timing Functions cubic-bezier(x1, y1, x2, y2), steps(), linear, ease-in-out
Fill Modes animation-fill-mode: forwards (retains end state) vs backwards
Standard W3C CSS Animations Level 1 & Level 2

Implementation & Code Examples

60 FPS Compositor Pulse Animation

@keyframes smoothPulse {
  0% {
    transform: scale(1);
    opacity: 0.9;
  }
  50% {
    transform: scale(1.05);
    opacity: 1;
  }
  100% {
    transform: scale(1);
    opacity: 0.9;
  }
}

.animated-badge {
  /* Runs entirely on GPU compositor thread */
  animation: smoothPulse 2s cubic-bezier(0.4, 0, 0.2, 1) infinite;
  will-change: transform, opacity;
}

Browser Rendering Performance & Hardware Compositing

Executing CSS Animations & Keyframes in modern web applications requires optimizing layout rendering across the browser rendering pipeline:

  • GPU Compositor Promotion: Restrict high-frequency dynamic transitions to compositor-only CSS properties (transform and opacity) to avoid triggering costly CPU layout reflows and repaints.
  • Layout Thrashing Prevention: Decouple DOM geometry measurements from subsequent style write operations to eliminate forced synchronous reflow cycles and preserve 60 FPS scrolling.
  • Subpixel Antialiasing: Design visual components with hardware-accelerated vector units and clamp scaling boundaries to eliminate visual pixel rounding jitter on high-DPI displays.

Frequently Asked Questions & Troubleshooting

Why does animating 'top', 'left', or 'width' cause stuttering and frame drops (jank)?

Modifying geometry properties forces the browser to recalculate layout (Reflow) and re-rasterize pixels (Paint) on the CPU for every single animation frame. Animating transform: translate() executes on the GPU without CPU reflows.

What does animation-fill-mode: forwards accomplish?

By default, elements snap back to their original keyframe 0% styling once an animation completes. Setting animation-fill-mode: forwards instructs the browser to retain styles applied by the final keyframe.
